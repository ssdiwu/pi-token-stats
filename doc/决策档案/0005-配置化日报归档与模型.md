# ADR 0005: 配置化日报归档与模型

## 状态

Accepted

## 背景

`pi-session-insights` 早期将日报自动写入 Obsidian vault；`pi-daily` 则只在 `--save` 时写入固定 Documents 目录。日报能力迁入后需要支持多天补写、稳定重跑和独立读取，同时允许 507 指定日报生成模型。

这会决定归档文件的长期位置、配置格式和模型成本归属，不能依赖隐式环境或把 API Key 写入插件配置。

## 决策

- 配置文件固定为 `~/.pi/agent/pi-session-insights.json`。
- `reportOutputDir` 未配置时使用 `~/Documents/pi-daily-reports`；默认日报和多天补写自动写入该目录，同日期覆盖 `YYYY-MM-DD.md`。
- `dailyModel` 使用 `provider/model-id:thinking` 选择器；配置不保存 API Key，认证沿用 Pi modelRegistry。
- 配置模型不可用或未认证时，显式记录后回退当前会话模型；当前会话模型也不可用时输出本地 fallback 日报。
- 不注册 `/daily` 兼容别名；日报入口仅为 `/insights daily`。

## 后果

- Obsidian 不再是日报默认归档链路；既有日报不会被迁移或删除。
- 归档路径与模型选择可在不修改 settings.json 的情况下调整。
- 批量生成必须逐篇记录实际使用的模型与回退原因，避免静默改变成本或文风。
