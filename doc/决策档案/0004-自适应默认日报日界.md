# ADR 0004: 自适应默认日报日界

## 状态

Accepted

## 背景

`pi-session-insights` 的数字洞察按自然日聚合，但日报需要覆盖跨夜工作。`pi-daily` 现有实现只在凌晨做 05:00 回溯，相关文档对“默认工作日是否始终从 05:00 开始”存在歧义。

日报归属同时决定缓存键、`YYYY-MM-DD.md` 归档文件名和多天补写的日期列表；若不先固定，凌晨生成可能出现拆分、覆盖或重复归档。

## 决策

未传显式日期、时间范围或 `--day-start` 的 `/insights daily` 使用自适应默认日界：

- `00:00–05:00`：日报归属昨天，范围为昨天 `05:00 → 当前时刻`。
- `05:00–24:00`：日报归属当天，范围为当天 `00:00 → 当前时刻`。
- `--day-start` 显式覆盖默认范围；其余显式日期/范围语义由对应命令参数决定。

## 后果

- 凌晨工作不会被拆入两篇默认日报。
- 白天日报继续与现有自然日数字洞察、缓存和稳定文件名对齐。
- 实现和测试必须以本地时间覆盖 `00:00`、`05:00` 两个边界。
